# Approval Boundaries

Allowed automatically in this demo:

- Local, low-risk mock tools
- Summaries and draft preparation
- Report-only dry runs

Requires approval:

- External messaging-like mock tools
- Medium/high-risk surfaces
- Any action that could affect another person or account in a real system

Blocked:

- Payment-like actions
- Unknown tools
- Anything marked `blocked` in config

This repo is intentionally simulated and does not perform live actions.
